# Ривер

## Патчноуты: обязательны для каждого релиза

- Любая заметная игроку правка сразу дописывается в `src/renderer/src/changelog.ts`, в запись следующей версии (она лежит первой). Нет записи для следующей версии: заведи её.
- Пишем для игроков, по-русски: что изменилось за столом и как этим пользоваться. Без внутренней кухни (рефакторинг, тесты, CI) и без точки в конце заголовка.
- Виды: `new` (новое), `better` (стало лучше), `fix` (исправлено). Заголовок в два-четыре слова, текст в одно-два предложения.
- Версия в `package.json` без записи в патчноутах роняет `npm test` (`src/renderer/src/changelog.test.ts`), а значит CI. Релиз берёт текст из той же записи (`tools/release-notes.mjs`) и без неё не выйдет.
- Игрок видит патчноут сам после обновления (окно «Что нового»), а весь список открывается в настройках и по номеру версии на главном экране.
